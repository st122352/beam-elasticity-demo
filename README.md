# Изгиб консольной балки: учебная модель

Мини-проект вычисляет прогиб, угол поворота и изгибающий момент в консольной балке постоянного сечения под действием силы на свободном конце. Модель основана на линейной теории Эйлера—Бернулли.

## Предположения и единицы

- малые прогибы и линейно-упругий материал;
- прямой призматический брус, постоянные `E` и `I`;
- сдвиговая деформация и собственный вес не учитываются;
- сила `P` направлена вниз и вводится положительной;
- SI: `L, x` — м, `P` — Н, `E` — Па, `I` — м⁴.

Формулы:

`v(x) = P x² (3L − x) / (6 E I)` — прогиб вниз;

`theta(x) = P x (2L − x) / (2 E I)` — наклон;

`|M(x)| = P (L − x)` — модуль внутреннего изгибающего момента.

На свободном конце `v(L) = P L³/(3EI)`, `theta(L) = P L²/(2EI)`. У корня `|M(0)|=PL`. Программа не является расчётным средством для проектирования конструкций.

## Запуск

Нужен Python 3.10 или новее, сторонних пакетов нет.

```powershell
python -m beam_demo --length 1.0 --force 100 --young 200000000000 --inertia 0.000001 --points 5
```

Проверки:

```powershell
python -m unittest discover -s tests -v
```
